# AI Workspace Proxy

Use this skill when the user wants to work with Google Workspace through the AI Workspace Proxy.

IMPORTANT: The skill root is the folder containing this `SKILL.md`. Resolve every relative path for local files, scripts, or Markdown files from the skill root, even when reading a nested file. For example, `./scripts/workspace_proxy_tool.py` means `<skill-root>/scripts/workspace_proxy_tool.py`, and `skills/<workspace-email>/GMAIL.md` means `<skill-root>/skills/<workspace-email>/GMAIL.md`. This does not apply to Google Drive `--drive-path` values, which are Drive subfolder paths relative to the registered Drive folder reference.
