# AI Workspace Proxy

Use this skill when the user wants to work with Google Workspace through the AI Workspace Proxy.

IMPORTANT: `{baseDir}` means the full path of this skill folder, the folder containing this `SKILL.md`. Use `{baseDir}` as the AI Workspace Proxy skill folder path. For Google Workspace commands, use the proxy tool script in this installed skill package: `python3 "{baseDir}/scripts/workspace_proxy_tool.py"`. This does not apply to Google Drive `--drive-path` values, which are Drive subfolder paths relative to the registered Drive folder reference.
