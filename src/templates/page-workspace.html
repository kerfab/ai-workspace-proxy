Workspace's friendly name

A friendly name lets you refer to this Workspace account naturally when asking an AI agent to work with it. For example: "Get my unread emails from my Perso mailbox."

Add an allowed Drive folder

  • This section is where you register Google Drive folders for this Workspace account.
  • Registering a folder here does not give AI agents access to it by itself.
  • Agent access is granted later, in the Agent access settings, where you choose which agents can use which registered folders.
  • The proxy only allows AI agents to work with Drive folders that you have registered and later allowed through agent access settings.
  • To register a folder, open Google Drive, right-click the folder you want to use, choose Share, then copy its link. Paste that link here and give it a unique Reference Name.
  • The Reference Name is the short name you and your agents can use in prompts instead of a full Google Drive link. It is also useful when different folders happen to have similar or identical names.
  • When a folder is registered, the proxy explores and caches its subfolder structure. This makes it possible to ask agents to work inside known subfolders without giving broader Drive access.
  • If subfolders are later added, moved, renamed, or removed inside a registered parent folder, use the "Refresh tree" button for that folder. This updates the proxy's cached folder structure so future agent instructions use the latest layout.
  • An agent can also request a tree refresh, but this should be done only when needed because it may consume Google API quota, especially for large folder trees.
